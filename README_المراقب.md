# المراقب المجدول (تنبيهات تيليجرام)

يفحص صفقتك المفتوحة كل 30 دقيقة **والتطبيق مغلق**، وينبّهك عند: تحقق TP1، ضرب الوقف/الهدف، اقتراب السعر من الوقف، وقبل حدث اقتصادي عالي التأثير بساعة تقريباً.

**قراءة فقط:** لا يكتب في السجل أبداً (حتى لا يتعارض مع حماية الـETag في التطبيق). التسجيل الفعلي للإغلاق يتم عند فتح التطبيق والضغط على «تحديث السعر»، وبنفس السعر لأن المحرك واحد.

## الإعداد (مرة واحدة)
1. ضع الملفات في جذر مستودع GitHub مع بقية التطبيق، ومعها `.github/workflows/monitor.yml` و`requirements-monitor.txt`.
2. من Settings ← Secrets and variables ← Actions أضف **أربعة أسرار**:
   - `GIST_TOKEN`: نفس قيمة `GITHUB_TOKEN` في أسرار Streamlit (رمز classic بصلاحية `gist`). الاسم مختلف لأن GitHub يمنع أسرار تبدأ بـ`GITHUB_`.
   - `GIST_ID`، `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID`: نفس قيم التطبيق.
3. تبويب Actions ← position-monitor ← **Run workflow** للتجربة. إن كانت لديك صفقة مفتوحة فسترى سطر "فُحصت ..." في السجل.

## يجب أن تعرف
- يحتاج تخزين **Gist** (لا يقرأ ملف التطبيق المحلي المؤقت).
- GitHub قد يؤخر المهام المجدولة عشر دقائق أو أكثر وقت الازدحام، فهو ليس لحظياً. للاحتياط ضع وقفاً حقيقياً عند وسيطك إن تداولت بمال حقيقي.
- المستودعات العامة تُعطَّل مهامها المجدولة بعد 60 يوماً بلا نشاط في المستودع.
- كل تشغيل ~دقيقة؛ `*/30` ≈ 1440 دقيقة/شهر (ضمن الحد المجاني للمستودع الخاص). غيّره إلى `*/15` إن كان المستودع عاماً.
- فشل المراقب نفسه (تعذّر السوق، تيليجرام، إعداد ناقص) يُفشل المهمة فيصلك بريد من GitHub.
- ذاكرة منع التكرار في كاش Actions؛ إن حُذف الكاش قد يتكرر تنبيه واحد قديم مرة أخرى.
- يعمل مع صفقة واحدة مفتوحة (كما يدعم التطبيق).
